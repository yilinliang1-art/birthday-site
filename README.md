# 给你的生日专辑

React + Vite 生日网页，包含黑胶开场、照片大图、半年时间轴、可拆信件与约会兑换彩蛋。响应式布局，支持减少动态效果偏好。

## 开发与预览

需要 Node.js 20.19+ 或 22.12+（当前环境 Node.js 24）。

```bash
npm ci
npm run dev
```

在开发环境的端口预览功能中打开 **5173**。本地电脑可访问终端显示的地址。

```bash
npm run build
npm run preview
```

构建输出在 `dist/`；生产构建预览使用 **4173** 端口。可将 dist 部署到支持静态网站的托管平台。部署到子路径时需配置 Vite 的 base。

## 替换内容

编辑 `src/content.js`：文字、日期、照片路径、信件、彩蛋及音乐都在此集中配置，并有中文注释。日期目前为示例，请按实际情况替换。

照片放到 `public/photos/`，路径如 `/photos/together.jpg`。空路径或加载失败会显示相纸占位图。音乐文件可放在 `public/`，设置 `music.src`，由访客点击后播放。请使用有权使用的照片和音乐，不要将私密素材提交至公开仓库。

无需后端、密钥或外部字体服务。所有记录均为页面静态内容。
